RAMESWARI (RANU) — DARK, MATURE BIRTHDAY WEBSITE

Includes:
- Dark plum/navy theme with restrained rose and champagne accents
- Wishes use Rameswari, Ranu, and SME Ma'am
- Birthday adventure with surprise buttons, mini-game, friendship certificate and secret ending
- Live countdown to Rameswari's next birthday: 8 October 2027
- Six-photo album with the cake photo first and a cute note button for every photo
- Uploaded music that plays after the visitor taps and loops between pages

Publish:
1. Create a new GitHub repository.
2. Upload index.html and the entire assets folder.
3. Go to Settings -> Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.
5. Open the GitHub Pages URL after publishing.

Keep the assets folder (including assets/photos and birthday-song.m4a) beside index.html.
